# Tom's Jukebox (Android)

One of Tom's Technology Solutions Products — *Focus On One Thing And Do It Well*.

Music player for the music on the phone, Australian and Vietnamese radio, podcasts and lyrics.
Android 7.0 (API 24) → Android 17 (API 37). Kotlin + Jetpack Compose + Media3.

The APK is built by GitHub Actions and saved on the `apk` branch.
Private repository: it holds the signing key.
